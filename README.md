# BFM Enterprise Mail

Build the actual production-ready BFM Email Management System described below.

This is a real internal enterprise application, not a visual mockup.

Before implementing functionality, establish a complete premium design system and apply it consistently across every page.

Focus heavily on:

premium enterprise UI

sophisticated UX

polished micro-interactions

smooth page transitions

excellent loading states

beautiful empty states

responsive layouts

Arabic RTL / English LTR

scalable component architecture

Do not generate fake business data.

The initial database state must contain no demo contacts, campaigns, reports, statistics, or activity.

Use realistic empty states instead.

The application must be designed so the backend and frontend can later implement the complete email sending architecture described in the project specification
